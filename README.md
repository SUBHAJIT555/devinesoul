# Swarveda

A Next.js site with the type, color, motion, and long-scroll rhythm of the reference marketing page. The purpose of the brand is still open.

## Scripts

```bash
yarn dev
yarn build
yarn lint
```

## Stack

- Next.js App Router
- Yarn
- Tailwind CSS
- Motion
- Geist for display and interface type
- Inter for captions

## Routes

- `/` Home
- `/about`
- `/courses`
- `/services`
- `/products`
- `/contacts`

Page copy is in `src/data`. The design rules for future edits are in `.cursor/skills/swarveda-design/SKILL.md` and `design.md`.
